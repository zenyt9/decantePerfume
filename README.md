# Décante — Үнэртэй усны жижиглэн худалдааны платформ

Ориг брэндийн үнэртэй усыг **5, 10, 20 мл** жижиг саванд савлаж зарах бизнест
зориулсан **бүрэн (full-stack) вебсайт**: хэрэглэгчийн бүртгэл, нэвтрэлт, сагс,
серверт хадгалагдах захиалга, болон бүх зүйлийг удирдах **админ самбартай**.

Нэмэлт npm сан шаардахгүй — зөвхөн **Node.js**-ийн built-in модулиуд дээр бүтсэн.

---

## 🚀 Хэрхэн ажиллуулах

Node.js (v18+) суусан байх шаардлагатай. Терминал дээр:

```bash
node server.js
```

Дараа нь:

| Хуудас | Хаяг |
|--------|------|
| 🛍 Дэлгүүр | http://localhost:4173/ |
| 🔐 Админ самбар | http://localhost:4173/admin |

### Анхны админ нэвтрэх мэдээлэл

```
И-мэйл:   admin@decante.mn
Нууц үг:  Admin@123
```

> ⚠️ **Эхний нэвтрэлтийн дараа** админ самбарын Профайл (эсвэл шинэ админ
> үүсгэх)-ээр дамжуулан нууц үгээ **заавал солино уу**. Анхны нууц үгийг
> `lib/seed.js`-ээс өөрчилж бас болно (сан үүсэхээс өмнө).

## ✨ Онцлогууд

### Хэрэглэгчийн тал (дэлгүүр)
- **Бүртгэл / Нэвтрэлт** — сагслах болон захиалахын тулд нэвтэрсэн байх шаардана
- **Профайл** — нэр, утас, хаяг, нууц үг өөрчлөх
- **Каталог** — ангилал, хайлт, эрэмбэлэлт, дэлгэрэнгүй цонх
- **Сагс** — серверийн үнэ дээр суурилсан, `localStorage`-д хадгалагдана
- **Захиалга** — серверт бүртгэгдэж, дугаар (жишээ: `DC-123456`) авна
- **Миний захиалга** — өөрийн захиалгын түүх, төлвийг хянах

### Админ самбар
- **Хянах самбар** — нийт захиалга, орлого, төлвийн задаргаа, сүүлийн захиалга
- **Бүтээгдэхүүн** — нэмэх / засах / устгах (нэр, брэнд, хүйс, 5/10/20мл үнэ,
  үнэрийн нот, өнгө, идэвх, эрэлттэй эсэх)
- **Брэнд** — нэмэх / устгах (ашиглагдаж буй брэндийг хамгаална)
- **Захиалга** — бүх захиалгыг харах, төлөв өөрчлөх (Шинэ → Баталгаажсан →
  Хүргэлтэд → Дууссан / Цуцлагдсан), захиалагчийн мэдээлэл засах

### Аюулгүй байдал
- Нууц үг `scrypt` + давс (salt)-аар хааш хийгдэнэ (ил хадгалагдахгүй)
- Session нь `HttpOnly`, `SameSite=Lax` cookie-гоор дамжина
- Захиалгын үнийг **сервер дахин тооцно** (клиентэд итгэхгүй)
- Админ эрхийг сервер тал бүр хүсэлтэд шалгана
- Өгөгдлийн сан (`data/db.json`) гадагш **задрахгүй** (allowlist)

```
│   ├── ui.js              # Дэлгэцэнд зурах + modal

└── data/
    └── db.json            # 💾 Бүх өгөгдөл (автоматаар үүснэ)
```

## 🔌 API товч тайлбар

| Метод | Зам | Тайлбар |
|-------|-----|---------|
| POST | `/api/auth/register` · `/login` · `/logout` | Бүртгэл, нэвтрэлт, гарах |
| GET/PATCH | `/api/auth/me` | Одоогийн хэрэглэгч / профайл засах |
| GET | `/api/products` | Бараа (админд `?all=1` идэвхгүйг оруулна) |
| POST/PATCH/DELETE | `/api/products/:id` | Бараа удирдах (админ) |
| GET/POST/DELETE | `/api/brands` · `/brands/:id` | Брэнд удирдах |
| GET/POST | `/api/orders` | Захиалга (өөрийн / бүх · үүсгэх) |
| PATCH | `/api/orders/:id` | Захиалгын төлөв, мэдээлэл (админ) |
| GET | `/api/stats` | Хянах самбарын статистик (админ) |

## 🎨 Өөриймшүүлэх

- **Брэнд нэр, утас, сошиал, хүргэлтийн харагдац:** [`js/config.js`](js/config.js)
- **Бараа, брэнд, үнэ:** Админ самбар → Бүтээгдэхүүн / Брэнд (кодгүйгээр)
- **Анхны суулгах бараа, админ нууц үг:** [`lib/seed.js`](lib/seed.js)
- **Хүргэлтийн төлбөр, үнэгүй болзол, хэмжээ:** [`lib/api.js`](lib/api.js) доторх
  `SETTINGS` (сервер тал) ба `config.js`-ийн `delivery` (харагдац)

---

## 💾 Өгөгдөл ба нөөцлөлт

Бүх өгөгдөл `data/db.json` файлд хадгалагдана. Нөөцлөх бол энэ файлыг хуулж
авахад хангалттай. Устгавал сервер дахин эхлэхэд анхны бараатайгаар шинээр
үүснэ (захиалга, хэрэглэгч арилна).

---

## ⚠️ Үйлдвэрлэлд гаргахаас өмнө (production)

Энэ нь жижиг бизнест бэлэн ажиллах хэмжээний MVP. Олон хэрэглэгчтэй, интернэтэд
байршуулах бол:

- **HTTPS** ашиглаж, cookie-д `Secure` нэмэх
- Файлын сангаас **жинхэнэ өгөгдлийн сан** (PostgreSQL/MongoDB) руу шилжих
  (зөвхөн `lib/db.js`-ийг солино)
- Онлайн төлбөр (**QPay**, картын гүйлгээ) холбох
- Rate-limit, и-мэйл баталгаажуулалт нэмэх

---

Асуулт, нэмэлт хүсэлт байвал хэлээрэй — QPay төлбөр, зураг байршуулах,
и-мэйл мэдэгдэл, эсвэл өгөгдлийн санг шилжүүлэх зэргийг цааш нэмж болно.
